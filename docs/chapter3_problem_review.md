# 第三章研究对象与全文主线的重新审查

当前 Word 第三章将预算内取得规划后缀定义为风险，使用四类概率和两边界决策选择切换时机。该形式化可以描述求解可靠性，却偏离了论文标题所指向的环境风险与车臂运动相互作用。继续增加分类器、状态机或对照数量，不能解决研究对象的偏移。需要先确定物理问题、可证明的边界及它与已有全身规划成果的关系。

## 需要纠正的研究对象

同一个机器人停在同一处障碍前，仅把优化预算从 100 ms 改为 400 ms，就可能使“预算内取得方案”的标签由失败变为成功。障碍、整机姿态和物理可行运动并未因此改变。于是，当前联合失效概率同时混入求解器表示、初始化、CPU负载和几何约束，其变化不能直接解释为环境风险变化。这一量可作为计算性能统计，作为第三章主线则需要与题目、物理机理重新论证。

当前 A 要求唯一 stow 终态，使许多已有巡检任务不适用。为建立两模式共同数据而把所有任务改成 stow 终态，会把研究缩成运输通行。原需求还包含主动车臂变姿及巡检目标姿态。必须同时保留 A 适用任务和只有 C 满足任务约束的任务，先用任务条件判定适用性，再研究可比较部分。该事实不要求增加第三模式或姿态库。

实测停稳、收臂到位与阶段推进构成系统运行的必要条件。由它们证明不会跳过运动阶段，只能得到顺序性质。若单独占据第三章主要篇幅，尚不能解释为何当前必须选择某种协调方式。连续运动控制的稳定性、可行性和无碰性，各需要相应假设及运动分析。

## 可以继续论证的物理主线

第三章更合适的候选主题是“任务与环境约束下的协调方式适用性及转换条件”。它需要回答以下三个问题，每个问题都必须有独立于第四章求解过程的物理含义。

第一，哪些任务与环境条件排除了某种组织方式？例如 A 的固定缩回臂姿能否满足任务要求、缩回整机能否经过受限区域、当前位置是否允许完整的原地收臂。静态缩回姿态合法与收臂过程合法分别判定。C 能沿程变姿并不意味着它在任意任务、任意初态上都可行。第三章定义这些限制的含义与证据范围；实际关节轨迹及通行路径由第四章生成。

第二，转换能否在尚有空间的区段内完成？用当前速度、制动能力、状态误差及完整收臂运动评价一个已得到的转换机会。仅在直线匀减速等明确假设下使用制动距离公式；完整车辆的轮组速率、转弯和扫掠碰撞按实际运动检查。可以研究状态偏差增大时，原来可执行的转换在哪个边界失效。当前只进行采样检查，不能把该检查直接称为全状态安全域或连续可达域。

第三，满足任务与物理约束的方式中，何种组织能缩短任务时间并减少无效停车？从实际候选的制动、收臂、行驶和接续时间比较，区分主动变姿产生的通行收益与随机多余关节运动。后续是否需要更复杂的风险模型，应由这些约束与简单代价无法解释的现象决定。

该方向仍需与HAMP、多模式规划及作者已有方法逐项对照。仅重写为裕度、可达性或图递推同样不足以确立新意。尤其需要避免把第四章的构型连接、关节搜索、制动轨迹和时间分配重新写成第三章的贡献。

## 第四章与整篇论文需要同步评估的取舍

第四章保留作者已经完成的耦合规划研究，明确其新增机制、基线和原始实验。解耦部分与该算法采用相同整机约束，解释阶段自由度、前后连接和失败类型。第三章只讨论方式适用与转换条件时，第四章负责求出满足这些条件的连续运动。两章可共享一次实验，但物理约束判断、求解质量与整机运行指标分别对应各自研究问题。

若第三章经过文献比较与场景分析后仍只剩“先生成两个完整方案再择短”，则独立成章的研究贡献尚不足。此时应考虑把风险表征作为第四章规划问题的统一约束基础，把方式选择作为同章的方法组成部分，重新组织第三章为已有研究能够支撑的实质方法。章节完整性应服从可验证的研究贡献。将动态 NMPC、CBF 或概率模型加入第三章会进一步扩大研究范围，必须有真实的任务动机、实现和证据。

因此，当前修订次序应是先完成一张“任务要求—排除哪种运动—能够观察到的物理原因”的表，再用现有模型核实至少两个不被单一净空解释的实例，最后才确定第三章的方法与目录。现有四分类标定与两边界策略暂作为已提出但受到质疑的备选。此前48次查询方案也只在选定该统计路线后才适用，不能继续作为当前必做工作的依据。
